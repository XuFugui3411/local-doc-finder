# v1.1.1 · 修复索引更新后搜索结果未刷新

索引任务在两次轮询之间快速完成时，旧版可能继续显示更新前的搜索结果。本版改为检测当前目录已提交索引的更新时间；更新成功后自动重新搜索，连续快速更新也能正确刷新。重复轮询不会重复搜索，较早的搜索响应不能覆盖新结果。

## Windows 用户下载

下载 **LocalDocFinder-1.1.1-windows-x64.zip**，完整解压后双击文件夹内的 **LocalDocFinder.exe**。无需安装 Python 或 Word。

升级时先退出旧软件，再运行新版；默认索引仍保存在本机同一数据目录，无需删除或重新迁移。正在打开的旧网页需要重新打开。

选择资料目录 → 建立 / 更新索引 → 输入关键词搜索。支持 Markdown、TXT、DOCX 和有文本层的 PDF。多个关键词要求全部匹配，英文不区分大小写。

EXE 与 _internal 文件夹需要保持在一起。如需桌面图标，右键 EXE → 显示更多选项 → 发送到 → 桌面快捷方式。
